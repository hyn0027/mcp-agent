# Study 2: Symbolic Enforceability of Security and Safety Requirements in Agent Benchmarks

Folder `CarBench`, `MedAgentBench`, and `tau2-airline` include all detailed annotation for the policies, and the jupyter notebook where we get all the statistics.

In folder `MedAgentBench`, there is a sub folder `policy_generation`, that contain all files, including code used to generate the policy. Please navigate to that folder for details.

Folder `fig_plot` include code we use to create figures in the paper.
